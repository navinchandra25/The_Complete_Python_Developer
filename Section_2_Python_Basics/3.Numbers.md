# Floating point number
A floating point number is simply a number with a decimal point.

In our case this is 0.5(2/4). 


Why do we need to make this distinction in programming and specially in python? Well its because a float takes up actually a lot more space in memory than an integer. Because remember this number, the number six this needs to get stored in memory on our machine and remember that machine don't really understand this. they understand 0 and 1. And they stored this number in something called a binary or binary numbers, which is 0 and 1. 

print(type(10.56))

Now the problem is when you have a decimal places like 0 point or lets do 10.56 its hard to represent that in a binary number 0 and 1 because of this point. So a floating point number essentially stores these numbers in two different location one for the 10 and one for the 56. 
Now we don't need to get technical here but that is idea. The idea is that we need more memory to store a number like floating point number than a integer.
